# Registro de Notas — Laboratorio 03 Tarea(Jetpack Compose)

Es una app en Kotlin + Jetpack Compose que calcula el promedio ponderado de 4 cursos (Fundamentos 20%, POO 25%, Móviles 30%, Base de Datos 25%).

Cada curso tiene un Slider (0-20, enteros) con un badge que muestra la nota en vivo y cambia de color (rojo/verde) según si es menor o mayor a 13.
Un Switch permite activar el redondeo del promedio final.
Un Checkbox de confirmación habilita el botón CALCULAR PROMEDIO.
Al presionarlo, calcula el promedio ponderado, aplica el redondeo si corresponde, y muestra una tarjeta con el resultado y un chip de color según la observación (EXCELENTE / APROBADO / EN RECUPERACIÓN / DESAPROBADO).
Un botón LIMPIAR reinicia todo el formulario a su estado inicial.
